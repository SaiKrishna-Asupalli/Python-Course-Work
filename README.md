# Python Course Work 🐍

A collection of Python programs and practice exercises completed while learning Python programming. This repository contains beginner-friendly examples covering fundamental concepts, conditional statements, loops, number problems, and pattern printing.


## 📚 Topics Covered

### Day 01 — Python Fundamentals
- Basic arithmetic operations
- Positive, negative, and zero checks
- Even and odd numbers
- Greatest and smallest of numbers
- Prime number checks
- Leap year and century year
- Palindrome numbers
- Vowel checking
- Temperature conversion
- Basic mathematical problems

### Day 02 — Conditional Statements
- `if`, `elif`, and `else`
- Nested conditional statements
- Grade and GPA calculations
- ATM simulation
- BMI calculator
- Discount calculation
- Ticket price calculation
- Month and number of days
- Password strength checking
- Time-based greetings

### Day 03 — Loops and Problem Solving
- `for` and `while` loops
- Factorial calculation
- Fibonacci series
- Prime number programs
- Multiplication tables
- Sum of numbers
- Sum of even numbers
- Reversing numbers
- Square calculations
- String and dictionary operations

### Day 04 — Pattern Printing
- Star patterns
- Number patterns
- Nested loops
- Basic pattern-printing exercises

## 🛠️ Technologies Used

- **Language:** Python 3
- **Editor:** Visual Studio Code
- **Version Control:** Git
- **Repository Hosting:** GitHub


## 🎯 Learning Objectives

- Understand Python syntax and fundamentals.

- Develop logical thinking and problem-solving skills.
- Learn loops and basic data structures.
- Improve programming skills through daily exercises.
